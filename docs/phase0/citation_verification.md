# Phase 0: citation verification and data availability

Checked 2026-11-17 against Europe PMC records (PubMed and PMC), Crossref DOI metadata, and the full text where it is open access (Europe PMC fullTextXML or the author PDF). "Verified" means the work exists with the stated bibliographic details and any quoted number appears in the full text. "Corrected" means the work exists but at least one detail in the prior sweep was wrong or needs a qualifier.

**Bottom line:** all 17 cited items exist. Two need corrections before they are used:

1. **Danov:** cite as *mBio* 2024;15(1):e01911-23. It is a general protein-toxin database, not a TA-specific one.
2. **Kearns & Shade H = 1326.6:** this is an rRNA-operon-count vs dormancy-gene test, not a habitat test.

One needs a qualifier: **Makarova "aquatic enriched"** is a genome-size residual, and the same analysis shows *terrestrial and multi-environment genomes depleted*. That runs against a naive "more variable means more TA" expectation.

## Data availability for the secondary predictors (niche breadth)

### Hao et al. 2026 PNAS (ProkAtlas habitat-cluster niche breadth): **available, per species, keyed by GTDB accession**
- Data statement: "Genome sequences and KofamScan functional annotation results data have been deposited in Figshare (10.6084/m9.figshare.31288942). Other data are included in the article and/or supporting information."
- Direct downloads:
  - All supplementary files (zip, 50.8 MB): `https://www.ebi.ac.uk/europepmc/webservices/rest/PMC12974524/supplementaryFiles`
  - figshare item 31288942 (API `https://api.figshare.com/v2/articles/31288942`). It lists Datasets S1–S20, for example S5 = `https://ndownloader.figshare.com/files/61724596`, S11 = `.../61724617`, S12 = `.../61724614`, S15 = `.../61724623`.
- **Key file: Dataset S5** (`pnas.2520645123.sd05.xlsx`, 5.2 MB). It has 25,785 rows, one per species. Columns: `Species_gtdb_genome_representative` (GTDB r207 accession, e.g. `GB_GCA_000007325.1`), `Genome_size` (in the authors' units, apparently a gene/KO count rather than bp, so check before use), cooperative-gene counts and proportions, **`Niche_breadth_number_of_cluster`** (integer, 1–26), **`Niche_breadth_generalist_specialist`** (Specialist/Intermediate/Generalist; generalist means ≥8 clusters), and GTDB taxonomy from domain to species.
  - Dataset S11: presence/absence in the 114 ProkAtlas habitats for 32,262 species.
  - Dataset S12: presence/absence in the 26 habitat clusters.
  - Dataset S3: mapping of the 114 habitats to the 26 clusters.
  - Dataset S15: alternative clustering threshold.

  - `hao2026_pnas_supplementary.zip`: 50,835,185 bytes
  - `supp/pnas.2520645123.sd01.pdf` … `sd20.xlsx` plus the SI appendix (`sapp.pdf`, 18,986,057 bytes)
  - `supp/pnas.2520645123.sd05.xlsx`: 5,168,264 bytes
  - `supp/pnas.2520645123.sd11.xlsx`: 11,903,521 bytes
  - `supp/pnas.2520645123.sd12.xlsx`: 2,678,277 bytes
  - `hao2026_datasetS5_species_niche_breadth.tsv`: 7,669,759 bytes, 25,785 species plus header, a TSV export of S5
- **Caveat for this project:** the data use GTDB **r207** accessions, while the project plans r232. Species representatives must be mapped across releases (via the GTDB metadata `gtdb_genome_representative` and species-cluster membership); some species will have been split, merged or renamed. ProkAtlas niche breadth is based on 16S presence, so it inherits 16S copy and resolution artefacts.

### von Meijenfeldt et al. 2023 Nat Ecol Evol (social niche breadth, SNB): **available, per taxon, keyed by NCBI taxonomy lineage**
- Data statement: Supplementary Data 1–9. The code is on Zenodo (doi:10.5281/zenodo.7651594, `code_for_paper.tar.gz`, 32.5 MB, `https://zenodo.org/api/records/7651594/files/code_for_paper.tar.gz/content`). A stand-alone SNB script is at `https://github.com/MGXlab/social_niche_breadth`.
- Direct download of all supplements (zip, 80.4 MB): `https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10172124/supplementaryFiles`
- **Key file: Supplementary Data 3** (`41559_2023_2027_MOESM6_ESM.zip` → `2023-02-01.Supplementary_Data_File_3.SNB.txt`). It has 20,785 taxa: **16,632 species**, 3,182 genera, 513 families, 222 orders, 95 classes, 138 phyla and 3 superkingdoms. Columns include `taxonomic lineage`, `rank`, `SNB`, number of samples, number of annotated biomes, sample counts per biome class, diversity metrics, SNB at alternative abundance thresholds, SNB by experiment type (amplicon/metagenomic), and PATRIC-derived genome features. Supplementary Data 4 holds the per-rank modified z-score (generalist/specialist).
- Downloaded to `/home/user/data/lit/vonmeijenfeldt2023/`:
  - `vonmeijenfeldt2023_supplementary.zip`: 80,394,039 bytes
  - `2023-02-01.Supplementary_Data_File_3.SNB.txt`: 18,314,075 bytes
  - `2023-02-01.Supplementary_Data_File_4.modified_Z-score.txt`: 1,059,202 bytes
  - The other supplement zips are under `supp/`. The 947 MB `table.MGnify.taxa_in_analyses.txt` in MOESM5 was not unpacked.
- **Caveat:** SNB is computed on **NCBI taxonomy** from MGnify profiles. Most of the 22,518 samples are amplicon data, so species-level SNB is noisy and the paper's analyses are mostly at genus level. Mapping to GTDB r232 needs NCBI taxid → GTDB species (GTDB metadata `ncbi_taxid`), which will be many-to-many for some lineages. Using **genus-level SNB** is the safer choice.
